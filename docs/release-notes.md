> **历史记录，部分内容已被取代。** 当前 UI 以 [ui-decisions.md](ui-decisions.md) 为准；下方保留原始发布记录。

1. **更舒展的顶部**：常用操作放在第一行，日期筛选和日历放在第二行；统一矢量图标，缩窄窗口仍可使用。悬浮横条只显示下一件任务，数量由圆球表达。
2. **搜索与编辑**：按 ⌘K 搜索任务、分组和任务视图，支持方向键选择和回车定位。编辑已有任务时 Return 保存并结束，连续新建继续保留输入上下文；拖动任务时显示目标位置。定位或悬停任务时，快捷操作不会遮挡日期。
3. **任务与历史**：任务服务完全原生化，界面与 MCP 共用数据并实时刷新，保留原任务、分组、设置和删除恢复记录，完成父任务时也会保留此前已完成子任务的历史。
4. **应用内 MCP**：提供查询、批量新增、修改、排序、删除恢复和定位等 17 个工具，设置可查看运行状态与连接数、复制客户端配置，关闭服务时会断开已接入的连接。
5. **系统要求与窗口**：最低系统要求提高到 macOS 26，统一使用 Liquid Glass，改善跨屏位置恢复与设置控件的键盘操作，保留系统无障碍偏好和原生 Sparkle 更新。
6. **Inbox 与分组**：固定 Inbox 收集未分类任务，拖到分组标签即可归类并带上子任务，已有同名分组会分别保留，也能正常撤销删除。
7. **独立分组面板**：每个分组都能打开独立面板或气泡，分别保留筛选、折叠状态与草稿，共享主面板的收放、悬停横条和淡出动效。

# 侧边便签

既定设计意图为按组着色的独立 Liquid Glass 便签；当前子窗口使用 `.paper`，呈现主题着色的半透明纸色背景，尚不能声称实机 Liquid Glass 已通过验收。便签静止露约 10 pt 且不显示文字，鼠标移到耳朵整体展开，宽度适配全名；间距 6 pt，全部固定第一，拖动与管理共享顺序，始终位于面板左侧并跟随面板；左侧空间不足时直接向内展开，不强制先收回再切方向，恢复向外展开保留 80 pt 迟滞，正常悬停展开与收回保留；四角柔和。

独立 `sideTabOpacity` 默认 85%，范围 10…100%，只作用于背景，随分组 `themeColor` 实时变化；降低透明度或提高对比度时使用实底。`SideTabAppearanceTests.swift` 覆盖离屏着色、不透明度及无障碍分支，`SideTabSettingsTests.swift` 覆盖设置默认值、范围及持久化；这些测试不等同于实机玻璃验收。

最终决定与守护测试见 [UI 决定](../../../../docs/ui-decisions.md)。示意仅说明结构，不作为实机验收。

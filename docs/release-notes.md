1. **字体切换**：设置中可分别选择中西文的衬线和无衬线字体，并即时预览和恢复默认字体。
2. **分组与面板**：分组便签随面板位置向内或向外展开，分组和已完成任务可折叠，删除分组后任务会移到无分组。
3. **搜索与日期范围**：搜索任务、分组和任务视图时以单行显示结果，日期筛选保留匹配子任务的上级上下文。
4. **新建与拖动**：空视图可聚焦输入栏、显示提示并带入当前分组或日期，跨组拖动时展示目标位置、层级和任务位移动画。
5. **快捷操作**：包括搜索在内的五项操作快捷键可分别设为全局、应用内或关闭，并支持多选、调整层级及会话内撤销重做。
6. **悬浮球与设置**：悬浮球显示剩余任务数，设置页面可搜索选项、调整透明度和配置工具栏按钮。

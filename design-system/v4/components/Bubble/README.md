# 悬浮球与横条

Liquid Glass 按当前分组主题色着色。48 pt 球只显示顶层未完成任务的剩余数字，绝无进度环或弧。悬浮球与横条统一使用 AppKit 系统 `hasShadow`；透明内容裁切决定阴影轮廓，形状、尺寸或着色变化及动画过程中刷新阴影，不使用独立阴影窗口或玻璃外的自绘实心阴影层。

横条高 48 pt，展开时圆保持原位。宽度为标题与单行元数据的较宽者加 78 pt（圆 48、圆与文字间距 18、外边距 12），上限为 440 pt 或屏幕可用宽度一半，不设 250 pt 下限；超长文字截断。圆在左、右两种朝向下，标题及元数据均左对齐。标题与可选元数据组成一个文字块，按最终截断字形的 CoreText 墨迹边界与圆心垂直居中；数字按实际墨迹居中。无元数据时仅显示垂直居中的标题。

最终决定见 [UI 决定](../../../../docs/ui-decisions.md) 与 [设计规范](../../SPEC.md)。`BubbleLayoutTests.swift` 使用真实 AppKit／`NSHostingView` 离屏 fixture 守护横条位置；`PanelShadowTests.swift` 守护系统阴影配置与单一背景轮廓。离屏窗口缓存不包含 WindowServer 绘制的系统外阴影。

[HTML 预览](preview.html) 的字体、留白和 CSS 阴影仅说明结构与朝向，不复现原生玻璃、CoreText 测量或系统阴影，不作为原生运行或实机验收证据。

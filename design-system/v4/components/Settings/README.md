# 设置

系统设置式布局：纯文字侧栏、顶部 Liquid Glass 搜索气泡、右侧分组容器与 44 pt 行、小开关；导航文字起点为 38 pt；颜色主题动态列出所有分组，全部颜色行显示「全部」／“All”，不附加 default color；所有色板为圆形，选中用外圈、不用对勾。外观分组提供便签背景透明度滑块，默认背景 alpha 85%，范围 0…100%，仅作用背景。

透明度统一数值越大越透明：主表面／便签背景 0…100%，失焦整窗 0…80%；通过 `100-opacity` 转换，历史字段值不迁移。四个字体行左预览 110 pt、右原生 picker 244 pt，控制框与文字起点一致，最小 800 × 540 pt 设置窗口内可滚动，长字体名完整显示。

最终决定与守护测试见 [UI 决定](../../../../docs/ui-decisions.md)。示意仅说明结构，不作为实机验收。

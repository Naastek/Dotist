**本人选定的白色玻璃**：悬浮球和横条采用单层原生玻璃，去掉额外自绘光边，保留原有去暗缘裁切。浅色无色外观使用白色 24% 原生染色，独立分组颜色、任务和其他设置继续保留。

**保留原生反光**：阅读底色和局部光边柔和地退入玻璃内部，避免普通颜色覆盖原生玻璃的反光边缘。保留染色、失焦常亮、透明度设置和分组修复。

**玻璃亮度与白色**：提亮原生玻璃染色，无色使用白色染色，浅色阅读底层改为白色；悬浮球和横条移除额外的黑色及颜色罩层，让原生反光直接呈现。保留失焦常亮、局部高光和分组空状态修复。

**分组横条修复**：空分组的收起横条改为显示无任务或已完成状态，不再把分组名重复当作任务标题；真实同名任务正常保留。
1. **XDR 玻璃光泽**：在支持 XDR 的屏幕上，悬浮球、横条和面板恢复系统玻璃自带的高亮光泽（亮度高于普通白色）；此前为去掉边缘深线裁得过深，把这些高光一起裁掉了。
2. **玻璃边缘**：面板、悬浮球和横条外围不再有任何一圈描边，只在受光处保留一段渐隐的高光；面板失焦变淡时也不再露出白圈。悬浮球和横条恢复通透的玻璃质感，颜色由玻璃自身着色给出，并修复了两行横条一侧多出的白底。
3. **主题色一致**：悬浮球和悬浮横条与面板使用同一主题色，输入框、标签补全、筛选条和提示条也随面板着色。
4. **更跟手、更省电**：展开、收起和拖动明显更流畅；面板空闲时不再持续占用处理器。
5. **统一的边缘与投影**：面板、悬浮球、横条、分组便签、任务视图、命令面板和快速添加不再有深色外圈，只保留浅色光边；投影统一为一套更柔和的样式。
6. **悬浮横条与滚动条**：横条文字与圆头边缘的间距加宽；所有列表改用自动隐藏的细滚动条。
7. **搜索定位**：从 ⌘K 打开任务时会展开所在分组、显示已完成任务并滚动到该任务；结果中不再出现内部的无分组项；面板去掉底部提示行，选中项改为圆角浅底。
8. **显示器变化**：更换或断开显示器后，面板不会大部分留在屏幕之外。
9. **细节**：任务视图中的完成与更多按钮更容易点中；分组与标签拖动排序遵循「减少动态效果」；分组删除按钮补充了辅助功能名称。

# 分组头

组名使用名字字体；点击组头折叠并持久化，折叠时组名旁出现小箭头。右键可更改分组颜色；无分组任务在全部视图顶部且无组头。

单一右箭头以 220 ms 平滑旋转至向下，槽宽覆盖完整旋转包络；标题宽度与完整墨迹固定。真实任务按完整固有高度连续裁切并渐显，后续分组连续移动；快速反向从当前值开始，减少动态效果立即切换。`FeedbackFourRegressionTests` 在实际 MainWindow 的全部／无日期路径中留帧，不以 clear 占位代替任务。

最终决定与守护测试见 [UI 决定](../../../../docs/ui-decisions.md)。示意仅说明结构，不作为实机验收。

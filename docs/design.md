# Dotist：Mac 第一版设计

> **历史记录，部分内容已被取代。** 当前原生架构见 [native-macos.md](native-macos.md)，当前 UI 决定以 [ui-decisions.md](ui-decisions.md) 为准；以下保留当时方案与验收证据。

## 范围
React + TypeScript + Vite 界面由 Tauri 2 承载。Mac 首次启动在主屏幕右上方显示可移动、置顶的轻量清单，并提供菜单栏显示、隐藏及退出。工作、生活、学习三组，支持任务新增、编辑、完成、恢复、删除和组内排序；长列表可滚动。输入法组合输入期间不提交。

## 数据与接口
Rust 任务服务以本地 SQLite 为唯一数据源，界面和本机 stdio MCP 共同调用该服务；不让两个入口分别维护数据。任务具备稳定 UUID、修改版本、更新时间、排序值和删除墓碑。每次修改与同步 outbox 记录在同一事务提交，供未来同步实现使用；不宣称这就是同步。UI 在外部变更后重新读取数据库。

MCP 提供按 ID 精确操作的任务工具，只在用户主动运行本机 server 后响应客户端请求；不接入第三方客户端，也不授予持久权限。日志不写入协议 stdout。

## 后续兼容
Android 以后单独适配，同一任务语义和同步协议；CloudKit 是主同步候选，当前只预留接口并研究可行性，不请求账号、容器、凭据或权限。不得把本地 outbox 误称已经完成 iCloud 或 Android 同步。

## 设计系统落地
视觉遵循 `design-system/`：透明毛玻璃窗口、一条对齐线、衬线仅用于「今天」和组名、原地编辑与撤销提示取代弹窗、一级子任务（`parent_id`，数据库版本 2）、悬浮球与菜单栏模板图标。

## 视觉与依赖
参考视频中的简洁分类小窗及 Arc UI 的免费 MIT 组件与交互：浅色、紧凑但可读，有键盘焦点、清晰状态、减少动态效果。不得购买 Pro 或配置 Arc MCP。首次启动不插入示例任务。独立测试目录与真实数据隔离。

## 限制
不部署、不支付、不外传任务内容、不改变系统安全设置、不安装全局工具链。标准项目依赖须列明并通过环境的必要审批。不得覆盖之前的 Swift 草稿或目标目录的已有文件。

# 侧边便签

既定设计意图为按组着色的独立 Liquid Glass 便签；当前子窗口使用 `.paper`，呈现主题着色的半透明纸色背景，尚不能声称实机 Liquid Glass 已通过验收。便签静止露约 10 pt 且不显示文字，鼠标移到耳朵整体展开，宽度适配全名；间距 6 pt，全部固定第一，拖动与管理共享顺序，始终位于面板左侧并跟随面板；左侧空间不足时直接向内展开，不强制先收回再切方向，恢复向外展开保留 80 pt 迟滞，正常悬停展开与收回保留；无轮廓描边；连接面板一侧为直角、外侧两角保留圆角（向外展开右侧连接，向内展开左侧连接）。

独立 `sideTabOpacity` 默认背景 alpha 85%，范围 0…100%，只作用于背景，随分组 `themeColor` 实时变化；降低透明度或提高对比度时使用实底。`SideTabAppearanceTests.swift` 覆盖离屏着色、不透明度及无障碍分支，`SideTabSettingsTests.swift` 覆盖设置默认值、范围及持久化；这些测试不等同于实机玻璃验收。

界面使用「分组便签背景透明度」，`100-sideTabOpacity`，默认 15%，范围 0…100%；仅背景响应，文字保持自身 alpha，无障碍仍用实底。

2026-11-02 第 5 项追加取代此前四角皆圆和加强描边决定。共享原生形状直接按 inward 方向选择两角半径；不新增表面装饰、配置或收回阶段。`SideTabAppearanceTests` 的双方向／收起展开／透明度端点／无障碍实底矩阵检查连接边每行贴齐、外角透明与零轮廓像素（白／黑底可见合成色差，原阈值 1/255，含旧 stroke 反例）；原有几何与完整文字检查继续保留；完全透明文字使用显式清零直接渲染与未激活原生视图双路验证，避免把缓存位图转换通道当作真实 alpha 证据。

最终决定与守护测试见 [UI 决定](../../../../docs/ui-decisions.md)。示意仅说明结构，不作为实机验收。

1. **玻璃常亮**：切到其他应用后，面板、悬浮球、分组便签和任务视图窗口的玻璃光边、厚度感与投影保持不变，不再整体变灰。
2. **材质设置生效**：主表面透明度与磨砂程度重新可调；「失焦后整窗透明度」改为「失焦后内容透明度」，只淡化内容，不淡化玻璃。
3. **分组便签与面板一体**：便签紧贴面板玻璃边缘，投影按面板与便签的整体外形绘制，便签不再被投影压暗。
4. **输入栏**：聚焦时显示为玻璃输入框，分组名、输入区与日历图标间距重排；点击空状态的加号时，玻璃从加号过渡到输入框。
5. **投影**：面板靠近屏幕顶部时投影不再与面板分离；任务视图窗口使用与面板一致的柔和投影和圆角轮廓。

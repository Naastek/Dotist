# 输入栏

组名使用名字字体，无下箭头；日历无箭头，仅悬停或聚焦显示，日期文字仅显式设置时显示。Return 连续创建同级，空任务丢弃。

空状态在文案下方显示居中加号（32 × 32 pt 命中区，辅助功能名称「在这里添加任务」），点击后清理互斥列表编辑并聚焦本输入栏；保留已有草稿，不在空状态插入编辑行、不创建空任务。添加分组与日期来自当前空结果筛选，自定义日期范围优先。焦点 binding 经可重入的 AppKit `makeFirstResponder` 交接取得本栏 field editor，挂载后重试，重复请求不重置选择或输入法组合文本。

placeholder 与 editor 同一时刻只能有一个绘制所有者；箭头位置须按真实原生窗口的墨迹验证。

最终决定与守护测试见 [UI 决定](../../../../docs/ui-decisions.md)。示意仅说明结构，不作为实机验收。

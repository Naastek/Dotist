标题菜单负责切换分组，替代原来的分组标签行；它是原生 `Menu`，在 macOS 26 上自带 Liquid Glass 和键盘导航。

**SwiftUI**：`Menu { … } label: { title }`，`.menuStyle(.button)`，`.buttonStyle(.plain)`，`.menuIndicator(.hidden)`。

菜单项从上到下：
1. **全部分组**，右侧显示总数。
2. 分隔线。
3. 每个分组一项：组名，右侧显示未完成数。
4. 分隔线。
5. **在独立面板中打开…**：在“全部”下展开为子菜单，列出各组。
6. **管理分组…**、**管理标签…**

细节：
- 当前项用系统勾选：`Toggle` 或 `Button` 加 `checkmark`，由系统绘制。
- 不自绘勾，不加左侧竖线，不铺底色。
- （可选，非本次范围）为分组切换加 ⌘1…⌘9 / ⌘0 快捷键；目前代码里没有。
- 拖动任务到某个分组，用 DragAndDrop 里的分组架完成，不依赖这个菜单。

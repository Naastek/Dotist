# 原生技术链路与交互收敛

当前支持的应用由 SwiftPM 构建：SwiftUI / AppKit 界面与应用内 MCP 共用 Swift TaskStore，GRDB 管理 SQLite 事务与变更观察。应用不再链接 Rust、C ABI 或网页运行时。

## 数据基线

直接承接当前 schema v5；启动不重写任务、分组、ID、父子关系、状态、日期、位置、修订、删除墓碑、remote_revision 或既有 outbox 记录。新数据库直接创建同一完整基线，不再包含 v1–v4 的逐版本升级链。高于或不属于当前基线的数据库拒绝打开，不尝试清空或降级。真实数据库的替换、恢复与安装仍应先正常退出应用并做 SQLite 一致性备份。

完成父任务只向下级联，子任务不会反向完成父任务。软删除按批次恢复；恢复任务必须确认原分组 ID 仍有效，不能用名称相同的新分组替代。日期采用严格本地 YYYY-MM-DD，新增带日期和批量新增在一个事务提交。

设置仍在数据库同目录的 settings.json 中，使用原子写入。当前安装设置可直接读取；不再处理废弃的 show_tray_count 等旧字段。自动检查与自动安装继续遵守依赖关系。

## 原生入口与 MCP

应用可执行文件的 --mcp 模式仅代理 stdio 与本机 Unix socket。实际服务使用官方 Swift MCP SDK，在应用内运行，每个客户端使用独立会话。默认关闭，设置中明确展示启用、运行与连接数。

冷启动 MCP 使用 --background 打开应用；普通读写不激活窗口，只有 focus_task 明确导航并聚焦。客户端写入使用与界面相同的 TaskStore，GRDB 观察推动界面刷新，不再定时全量轮询数据库。批量输入遇到任一非法项整体回滚，未知输入字段返回错误。

GUI 和 --mcp 入口都先验证 QA 专属数据目录，避免验收包意外连接正式数据库。socket 只接受当前用户所有的连接文件，权限为 0600；停止只回收本服务创建的资源，崩溃残留通过连接探测后恢复。

## 主面板与图形

第一行将 Dotist 图标合并为搜索入口，并放任务视图、置顶、固定、收起。文件夹索引标签切换分组；下方放可滚动日期筛选与固定日历入口。选中日期筛选更大、更粗，其他标签随距离减淡，宽度槽位保持稳定。设置继续通过菜单栏或快捷键打开，不增加重复主面板入口。

顶部图标共用 24pt 矢量网格、1.55pt 圆角描边和统一的实际显示尺寸，由 SwiftUI Path 绘制。图钉开启仍为竖直实心，关闭倾斜空心。图形语言概念参考 Tic 网站使用的 Phosphor 图标，未引入 SVG/网页渲染器。

横条只显示下一件任务，数量仅由圆球表达。已有任务 Return 保存并结束编辑，连续新建保持原输入上下文；悬停说明使用系统 tooltip，不显示底部提示行。行操作与内容处于同一稳定命中区域，默认隐藏，悬停或键盘聚焦显示，删除使用叉号；日期本身兼作修改入口。底部输入按真实分组名和日期宽度布局，不够宽时换行，保留同一个编辑器与草稿，不显示剩余数量。搜索支持任务、分组与任务视图，⌘K 由原生菜单统一路由，协调键盘和鼠标选择；导航会清除旧标签筛选并展开目标任务所在折叠区域。

内部 inbox 是隐式无分组桶，不在分组列表中展示；默认无分组的新增任务进入该桶，已有分组选择优先。删除分组时任务迁移至无分组。拖动归类复用任务服务，父子关系、日期、状态及历史保持一致。

每个分组可以打开独立面板并单独收成气泡。各面板共享 AppModel 的数据与写入服务，TaskPanelState 独立持有分组、日期筛选、标签和展开/折叠状态；收成气泡时保留原 MainWindow，不重建草稿。所有面板统一复用 PanelMotion 与 FloatingPanelView：完整保留收起/展开、内容渐变、悬停横条、延迟撤回、失焦淡出、自动收起和系统减少动态效果；每个实例的状态相互独立。气泡拖动结束后统一限制在屏内，并按所在屏幕左右侧选择横条展开方向。任务视图打开时与主面板同步层级并置前。

分组、父子关系、标签与悬浮球统计在数据变更时建立索引；拖动期间暂存外部快照；主列表、月格摘要、任务卡片与甘特名称均由 SwiftUI 拖动会话 ended 回调处理成功或取消，再应用最新状态，不再轮询全局鼠标按键来猜测拖动结束。屏幕拓扑变化只临时调整窗口可见位置，不覆盖用户原来的偏好。

## 构建与更新

版本、系统要求和公开更新密钥统一放在 native/app.json，SwiftPM 的平台版本也从该配置读取。最低系统基线为 macOS 26；窗口材质与控件统一使用 Liquid Glass，不再保留较早系统的材质、拖动、焦点或动画分支。系统减少透明度、增强对比度与减少动态效果仍按无障碍偏好处理。

使用 bash native/scripts/test-native.sh 验证，bash native/scripts/build-qa.sh 构建隔离验收包，bash native/scripts/build-local.sh 构建正式候选包。脚本不安装应用。Node、Tauri 和 Rust 不属于当前构建或发布链路。

只发布原生 Sparkle appcast 与原生归档，不再生成 latest.json、minisign 签名或 MCP sidecar。SPARKLE_SIGNING_PRIVATE_KEY 必须是与 native/app.json 公开密钥匹配的 Sparkle 私钥，通过 stdin 交给官方 sign_update。现有公开信任根保持不变；CI 密钥格式切换应在下一次获准发布前完成，不能通过换公钥或跳过验证解决。

更新验收使用一次性测试密钥和专用 QA 包，覆盖正常检查、手动安装、篡改拒绝、退出时自动安装、取消暂存和跳过版本。测试密钥不写入产品配置，测试结束移除私钥并保留公开验收证据。

退役的 React/Tauri/Rust 客户端、专用测试与旧发布工具已移除。设计源文件、历史文档及静态预览继续保留；预览使用的四份 CSS 已原样迁到 design-system/previews/styles。历史文档中记录的 npm/Cargo 命令、旧路径及验收结果仅描述当时实现，不再是当前可执行入口。原生 MCP、schema v5、sync_outbox 与现有兼容处理保持不变。

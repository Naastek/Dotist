1. **更跟手、更省电**：展开、收起和拖动明显更流畅；面板空闲时不再持续占用处理器。
2. **统一的边缘与投影**：面板、悬浮球、横条、分组便签、任务视图、命令面板和快速添加不再有深色外圈，只保留浅色光边；投影统一为一套更柔和的样式。
3. **悬浮横条与滚动条**：横条文字与圆头边缘的间距加宽；所有列表改用自动隐藏的细滚动条。
4. **搜索定位**：从 ⌘K 打开任务时会展开所在分组、显示已完成任务并滚动到该任务；结果中不再出现内部的无分组项；面板去掉底部提示行，选中项改为圆角浅底。
5. **显示器变化**：更换或断开显示器后，面板不会大部分留在屏幕之外。
6. **细节**：任务视图中的完成与更多按钮更容易点中；分组与标签拖动排序遵循「减少动态效果」；分组删除按钮补充了辅助功能名称。
